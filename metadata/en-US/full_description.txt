<p><strong>IMS configuration for Google Pixel Tensor devices on mainland Chinese carrier networks, independently maintained by Mystery00.</strong> Requires a Google Tensor Pixel device, Android 13+, and privileged access via the backend you explicitly select.</p>
<p>Primary maintenance focuses on China Mobile, China Unicom, and China Telecom. Other carriers may also work, but compatibility must be verified on the target device.</p>

<h2>About</h2>
<p>TensorIMS lets you read and configure IMS and carrier settings such as VoLTE, VoWiFi, VT, VoNR, Cross-SIM Calling, UT, USSD method, and 5G NR modes on Google Pixel phones. External mode uses <a href="https://shizuku.rikka.app/">Shizuku</a> (or compatible forks); embedded mode runs a private service via wireless ADB pairing, computer ADB, or existing root access.</p>

<h2>Features</h2>
<ul>
<li><strong>IMS Configuration (Draft Mode)</strong>: Real-time CarrierConfig snapshots grouped into Calling, Network, Display, and Custom Overrides, with quick presets (Recommended, China 5G, China LTE, Enable all) plus one custom saved preset (My preset).</li>
<li><strong>Calling &amp; Network Controls</strong>: VoLTE, VoWiFi &amp; roaming VoWiFi, Wi-Fi Calling name format, VT, VoNR (Android 14+), Cross-SIM Calling, UT, USSD connection method, 5G NR &amp; NR architecture mode (NSA + SA / SA only / NSA only), 5G signal thresholds, 5G+/5GA icon, Enhanced 4G LTE (LTE+), Show 4G for LTE, and Always Show Cellular Network Type.</li>
<li><strong>Automation &amp; Persistence</strong>: Optional auto-start of embedded service on foreground launch (reusing existing wireless pairing), optional auto-apply when the selected backend is ready after reboot, and experimental Persistent VoLTE (VoIMS opt-in).</li>
<li><strong>System Network</strong>: Manage global Captive Portal detection URLs (<code>captive_portal_http_url</code> / <code>captive_portal_https_url</code>) with built-in presets. Note: some Android/NetworkStack builds may prioritize resource overlays over SettingsProvider values.</li>
<li><strong>Diagnostics &amp; Maintenance</strong>: Real-time IMS status snapshot, IMS restart, in-app Logcat viewer &amp; export, and single-SIM CarrierConfig override reset.</li>
</ul>

<h2>Requirements</h2>
<ul>
<li>Google Pixel devices with Google Tensor chips (Pixel 6 series through Pixel 11 series, Pixel Fold, Pixel Tablet). Qualcomm Snapdragon Pixels (Pixel 5 and older) are NOT supported.</li>
<li>Android 13 or higher.</li>
<li>External Shizuku (running &amp; authorized) or embedded mode started via wireless debugging pairing, computer ADB, or root.</li>
</ul>
