# 真机验收与安全迁移

本文件是待执行的验收清单，不是已经通过的测试报告。

## 安装前
1. 保留旧版 TensorIMS 和它的数据，先关闭旧版自动恢复。
2. 在旧版内恢复已修改 SIM 的持久化 VoLTE 原始值；暂未激活的 SIM 需要重新激活后恢复。
3. 确认原值恢复后安装新包 app.mystery0.ims.tensor；它与 io.github.vvb2060.ims 是两个独立应用，不能覆盖升级，也不读取旧包私有目录。
4. 新包首次明确选择官方或内置模式，先读取当前配置，再决定是否写入。新包首次使用持久化 VoLTE 时建立自己的恢复备份。
5. 不同时打开两版自动恢复；验证新包恢复功能前，不卸载旧版或清理其数据。

## 测试记录必须包含
- 设备型号、系统完整构建号、安全补丁、Android 版本
- 应用 commit、APK SHA-256、签名证书 SHA-256
- 后端 OFFICIAL/EMBEDDED，服务身份 shell/root，启动方式、协议/版本
- SIM 槽位、运营商、是否双 SIM（不要记录完整 ICCID/IMSI）
- 初始状态、操作、回读、清理、恢复结果和脱敏日志

## 首次选择与切换
- [ ] UNSET 取消/返回/旋转/后台恢复不选择后端，不启动服务
- [ ] 官方不存在或拒绝授权仍保留 OFFICIAL，不启用内置
- [ ] 无线配对和 root 仅在点击后请求；设置页不改全局 ADB 开关
- [ ] 空闲双向切换保留历史和持久化 VoLTE 原值备份
- [ ] 写入中/结果未知时拒绝切换；重复点击不排队启动
- [ ] 旧 epoch/operationId 的迟到回调不污染当前模式

## 故障与恢复
- [ ] Binder 死亡、应用进程死亡、设备重启分别验证
- [ ] 配对撤销、无线调试关闭、root 拒绝显示正确修复阶段
- [ ] 应用更新/安装目录变化使用当前 APK，旧会话失效
- [ ] 写入超时不自动重放，旧任务终态或重启后先只读核对
- [ ] 清理失败保持恢复态，不能继续普通写入
